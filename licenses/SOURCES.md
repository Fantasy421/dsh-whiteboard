## Coverage and unresolved release questions

- **Liberation Sans 1.05: OMITTED from this plugin's packaged font assets.** Its redistribution terms remain unresolved: the release binary only refers to the agreement under which it was accepted and `http://www.ascendercorp.com/liberation.html`, without including that agreement. Do not substitute modern Liberation 2.x OFL or assume Excalidraw MIT relicenses it. Before adding this binary, verify its historical license and source/notice obligations or obtain permission. [Metadata](./Liberation-METADATA.txt) is retained for audit only; it does not grant a license.
- **Cascadia:** release nameID 13 contains a restrictive Microsoft boilerplate paragraph followed by an explicit OFL-based redistribution grant. Both are retained in [metadata](./Cascadia-METADATA.txt). Release version `2005.150` corresponds to upstream tag `v2005.15`; its exact OFL text is included. Resolve the inconsistent embedded wording with the rightsholder if an unambiguous distribution clearance is required.
- **Lilita:** release metadata reserves `Lilita One`; supplemental upstream OFL reserves `Lilita`. Preserve both notices and avoid modified font naming under either name without permission.
- **Xiaolai:** release source declares OFL 1.1 and records prior subsetting/spacing modifications (removed non-CJK codepoints, Hangul side-bearings reduced to 40%, centered miscentered CJK codepoints). The full standard OFL text here is from the same release Virgil metadata, not a nonexistent Xiaolai standalone license.
- OFL fonts must retain applicable copyright and license notices; do not sell a font by itself or use reserved names for modified versions without required permission. These observations are not a legal opinion.
