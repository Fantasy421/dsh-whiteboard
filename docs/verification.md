## 当前证据边界

- **已发布版本**：v0.3.0 发布时 158 项自动化测试及生产构建通过。
- **本次文档与示例更新**：`npm run check` 实际通过 **162/162** 项测试及生产构建；新增四项示例确定性、显式绑定、证据表述/打包声明和相对链接校验。另通过 `git diff --check` 与 `npm pack --dry-run --ignore-scripts`。这次仅发布源码仓库文档/示例更新，不替换 v0.3.0 Release 二进制或当前安装。
- 自动化覆盖包括阅读模式、网页嵌入误操作白屏修复、紧凑顶部、多白板、线型编辑和刷新修复等回归。
- **真实 GUI 尚未完整验收**：侧栏画布、手绘、导出、焦点、撤销、第三方对话框等仍需在原 DSH 实机检查。
- **当前没有已完成的真实演示录像或 GIF。** 下方全部是待验收项，不代表通过；后续应按实际证据逐项更新，不因一段演示就批量勾选。
- **本轮录制的具体障碍**：BrowserSkill CLI `0.4.2` 已安装，但 doctor 检查报告 `0 browsers connected`；用户当前不在电脑前，无法安装或连接 Chrome 扩展，因此本轮无法进行真实浏览器录制。此项是录制环境限制，不是插件功能通过或失败的证据。需连接浏览器后再补实录；代码构建的示例或可导入演示图不能替代实录。

组件回归测试以原生编辑器桩验证挂载次数、同步会话、视图控件和生命周期。网页嵌入回归使用实际白板组件与原生 `componentDidUpdate → onChange` 行为桩；阅读模式包含双阶段原生切换生命周期、只读图片缓存隔离和画框裁剪的测试。

这些测试**不替代真实浏览器的视觉布局、点击命中、键盘焦点、撤销、触屏手势或第三方对话框验收**。后端工具调用成功也不能单独证明 GUI 联调通过。

## 建议记录方式

每次实机验收记录插件/DSH 版本、使用的安装包、操作步骤、预期/实际结果和对应证据。仅用新建虚构会话与演示图，不访问或暴露真实用户白板、聊天历史、个人资料、令牌及路径。

记录必须来自原 DSH GUI。若等待被省略或加速，应明确标注，不能根据剪辑后的时长宣称同步延迟。GIF 可演示某条路径，不等于覆盖异常处理、持久化和并发安全。

## 安装、编辑与同步

- [ ] 在原 GUI 出现侧栏入口；打开后画布可见、无重复 React 报错。
- [ ] 手画矩形、箭头、自由笔和中文文字；等到状态“已保存”。
- [ ] 不出现网页嵌入入口；通过命令面板或导入不支持的网页对象时，仅显示提示并回到选择工具。连续点击、拖动后仍可绘图/撤销，原有未保存草稿保留，无更新深度错误。
- [ ] 删除对象后撤销，再刷新，恢复后的对象仍存在。
- [ ] 让 AI 画三个带标签节点和两条箭头，观察实际更新及延迟；“约一秒看到变化”需由实际测量支持，不根据加速录像判断。
- [ ] 选择对象，AI 读取选区并仅修改该对象。
- [ ] 人工和 AI 修改不同对象可合并；同时修改同对象出现冲突，不覆盖。
- [ ] 下载本地源文件后，确认加载服务器版本可以解除冲突。
- [ ] 切换会话不串图；关闭重开、重启应用后恢复。
- [ ] 中文字体、PNG / SVG / 源文件导出均正常；实际下载并打开产物，而非只点击菜单。

## 紧凑顶部与大屏

- [ ] 在窄侧栏及大屏模式下，“更多”中的缩放控件和「大屏编辑 / 返回侧栏」可用；反复切换不丢失绘图、选区和撤销历史。
- [ ] 管理默认关闭且不占高度；与“更多”互斥，错误/草稿警告始终可见；短窗口面板可滚动，键盘展开后进入面板，关闭后焦点返回。
- [ ] 窄侧栏长标题正确截断，不挤占必要控件。
- [ ] 空闲 Esc 返回侧栏；文字编辑、对象选择、原生菜单和对话框优先处理 Esc。
- [ ] 大屏内清空确认对话框正常显示；隐藏、关闭或切换会话后，不留下大屏遮罩。
- [ ] 原生画板快捷键只在画板聚焦时处理，不全局抢占 DSH 快捷键。
- [ ] 缩放以视口中心为锚点，百分比按钮恢复 100%；大屏切换不自动重置缩放或平移。

## 连线样式

- [ ] 选中线条/箭头后切换直线、曲线、折线；未选中和已锁定的线条不被修改。
- [ ] 双击线条后控制点可继续编辑，标签随线移动。
- [ ] 走线样式切换可撤销/重做，等待保存后关闭重开不丢失；AI 指定 `lineStyle` 与人工转换效果一致。
- [ ] 旋转连线转换保持端点位置，重新绑定保留世界坐标拐点；检查标签布局与原生手绘笔触的实际偏差，不声称像素级重合。

## 同会话多白板

- [ ] 同会话创建三张白板，分别绘图；搜索、下拉、上一张/下一张及大屏内导航均正常，切换不串图或撤销记录。
- [ ] 离线或冲突时切换被阻止，未保存内容仍可导出；保存成功后再切换，关闭重开恢复正确首选白板。
- [ ] 重命名后列表更新；删除需确认且最后一张不可删。
- [ ] 其他窗口删除当前白板时保留草稿，显式导出/确认关闭后才退出。
- [ ] AI list/manage/read/patch 指向正确 ID；目录与场景 CAS 冲突分别处理，旧 default 内容不变。
- [ ] 管理操作期间的输入冻结与草稿二次检查正常，未知目录结果不重复新建或删除。

## 阅读模式

- [ ] 从“更多 → 阅读模式”进入，点击流程节点，焦点橙色、直接相连的线和邻居蓝色，入边/出边及对应文字标签正确。
- [ ] 只追踪显式绑定的一跳关系；不递归追踪整链，不把几何交叉或靠近的线误判为连接。
- [ ] 点击空白或按 Esc 清除高亮；顶部“退出阅读模式”恢复编辑，原有选区与撤销历史不丢失。
- [ ] 窄侧栏与大屏中点击命中正确；平移、缩放、右键菜单和多指手势不误触节点高亮。
- [ ] 阅读期间禁止拖入/粘贴等编辑输入；原有待保存草稿仍可保存，AI 远程修改仍同步。
- [ ] AI 更新或删除焦点节点后，高亮与实际场景一致，不残留错误引用。
- [ ] 旋转节点、曲线/折线与画框裁剪表现正确，不可见的框外内容不能被点击选中。
- [ ] 切换白板重置阅读状态；隐藏或关闭画板清除高亮。
- [ ] 图片异步导入及进出阅读模式后缓存/选区正常，不串写到另一图。
- [ ] 对照场景与导出文件确认高亮不改元素颜色、版本、共享选区或导出内容；单看一段高亮 GIF 不能证明这些数据不变量。

## 哪些结论不能从演示外推

- 看见 AI 新增节点，不证明选区定向编辑、冲突保护或所有工具参数正常。
- 切换三张演示图，不证明跨会话隔离、离线草稿保护、撤销隔离或重启恢复。
- 点开导出菜单，不证明 PNG/SVG/源文件已生成且可打开。
- 在桌面点中节点，不证明触屏、多指、所有缩放等级或画框裁剪已验收。
- 测试/构建通过，不证明当前桌面已安装新包，也不证明真实 GUI 没有 React、布局或焦点问题。

验收结果应保留“已验证 / 未验证 / 失败”区分。失败项记录实际问题，不能用测试数量或发布版本号代替修复证据。
