# 数据、恢复与安全边界

[返回首页](../README.md) · [AI 工具](ai-tools.md) · [实机验证状态](verification.md)

以下描述当前实现与设计约束，不代表全部场景已通过实机验收。白板内容可能包含敏感信息，导出、截图或分享前应自行检查。

## 本机存储与容量

默认数据根目录为 `~/.dsh/whiteboards`：

| 内容 | 相对数据根目录的路径 |
| --- | --- |
| 旧/默认白板 | `<SHA256(sessionId)>.json` |
| 多白板目录 | `catalogs/<SHA256(sessionId)>.json` |
| 新白板场景 | `boards/<SHA256(sessionId)>/<boardId>/<SHA256(sessionId)>.json` |

`boardId` 只允许 `default` 或服务端生成的小写 UUID。会话 ID 不作为路径片段，文件权限为 0600。旧单白板文件继续作为 `default`；读取不会迁移或重写原数据。

- 单会话最多 100 张存活白板、1000 个累计目录条目（含删除记录）；目录上限 512KiB。
- 删除后 ID 不复用，超过目录上限需另开会话。
- 每个场景最多 2000 个元素，包含文字标签和删除墓碑；场景 JSON 上限 8MiB。
- 每条线最多 20000 个控制点。满额共线线条切换曲线需要新增拐点时，会拒绝转换，不覆盖已有控制点。
- 超出场景限制会显示保存失败，保留本地内容供导出；重试不能突破限制。

按会话保存的是元素、内嵌 PNG/JPEG/WebP 图片和选区。缩放、背景色、网格等个人视图状态不持久化。撤销历史只在本次打开的白板中有效，不作为持久化历史保存；切换白板会重建原生编辑器，撤销历史不跨白板保存。

## 同步与冲突

活跃画板约每秒同步，停止输入后约 550ms 尝试自动保存；网络和操作耗时不计在内。这是机制说明，**不是实机响应时间承诺**。

同步采用版本号 CAS 与对象级三方合并：不同对象的并发修改可合并；同一对象冲突时暂停同步，保留本地修改，不静默覆盖。即使修改的是同一对象的不同字段，也可能触发冲突；这不是字符级 CRDT。

请求超时后释放同步队列，取消拖动或窗口失焦后恢复轮询；保存回包丢失时先读取确认，不盲目覆盖。额外并发版本使结果无法确认时，仍保守暂停。

目录版本与各图的场景版本独立。AI 必须保留读取时的目标 ID，冲突后重新读取并重新评估，详见[AI 工具](ai-tools.md)。

**目录与场景的串行锁只保证同一服务进程内安全。不要让多个 DSH 进程共享写入同一数据目录。** 当前不含跨进程分布式锁、多人远程协作、无限历史或模型 token 级动画。

## 草稿、浏览器备份与恢复

浏览器保留按会话/白板隔离的本地恢复备份，容量受浏览器限制；旧 `default` 的浏览器备份键保持兼容。不要把浏览器备份当作无限容量或独立的长期备份服务。

发生冲突时：

1. 保留当前草稿，先下载可编辑源文件。
2. 检查本地与服务器版本差异。
3. 只有在明确接受丢弃当前本地版本时，才选择加载服务器版本。

保存失败或达到容量限制时，保留本地内容供导出。不要靠重复保存、切换白板或提高版本号绕过限制。

## 多白板切换与删除

点击顶部名称展开管理区，可搜索名称/ID、下拉直达或上一张/下一张切换。名称最长 80 个 UTF-16 单元，可重名，以稳定 ID 区分。

- 切换前尝试保存；离线、保存失败、冲突或原生编辑尚未结束时，不强制跳转。
- 目录操作期间暂时冻结当前画布输入，再检查一次草稿是否安全。
- 其他窗口或 AI 修改会话首选图，不会强行拉走已打开视图；关闭重开时按会话首选图加载。
- 删除只从目录隐藏，不清除磁盘文件；当前没有恢复入口，删除前先导出。不能删除最后一张白板。
- 若其他窗口删除当前图，编辑器保留草稿供导出；明确点击「关闭已删除白板」并确认后才离开。
- 目录请求超时只重新读取结果，不自动重复新建或删除。

卸载插件不会自动删除画板数据，见[卸载说明](installation.md#卸载)。

## 内容与网络边界

同步复用 DSH 已认证接口，不新增端口、不创建公网无鉴权 API。字体也通过现有 DSH 已认证 `/api` 端点提供。

画板内文字不会被执行；图形、名称和文字均是用户数据，不应成为 AI 指令。当前不接受：

- iframe 或网页嵌入；
- 活动脚本链接；
- SVG 图片；
- 远程图片引用。

文本中可以正常讨论代码，文本本身不执行。不要编辑源文件绕过内容校验。

网页嵌入白屏修复并不意味着支持网页嵌入：误导性的原生入口已隐藏；命令面板、粘贴和导入仍经过运行时检查。拒绝不支持内容时恢复最后已接收的本地草稿，而不是直接加载服务器版本；回退仅作用于原画板实例，不写入切换后的另一张图。其生命周期回归测试不等同于实机验收。

## 阅读模式不等于内容编辑

阅读模式只追踪原生显式绑定的一跳入边、出边、邻居与对应文字标签；不递归追踪整链，也不把几何交叉或靠近猜成连接。

高亮为指针穿透的本地 SVG 覆盖层：不修改图形颜色、版本或共享选区，不写入导出文件。阅读期间禁止拖入/粘贴等编辑输入，但原有待保存草稿仍可保存，AI 远程修改仍继续同步。

点击空白或按 Esc 清除高亮；退出模式恢复编辑，切换白板重置阅读状态，隐藏或关闭清除高亮。覆盖层使用理想几何而非原生随机手绘笔触，不额外绘制箭头头部，不承诺像素级重合。旋转、画框裁剪、手势、模式切换与撤销等 GUI 行为仍须实机验证，见[验证状态](verification.md)。

## 字体与离线限制

插件默认打包浏览器所需字体（含中文），首次包体较大。旧版 Liberation 1.05 属于上游服务端渲染字体，其历史授权尚待核实，本包不分发该字体。

本地字体不可用时，上游库可能尝试自己的 CDN fallback，因此**不能将本插件称为严格断网模式**。第三方许可见[第三方说明](../THIRD_PARTY_NOTICES.md)。
