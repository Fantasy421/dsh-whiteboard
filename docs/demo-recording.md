## 恢复录制的条件

1. 用户在 Chromium 中安装/开启 [BrowserSkill 扩展](https://chromewebstore.google.com/detail/hhcmgoofomhgciiibhipgmgkgnoenaoi)，连接本机 daemon。记录时端口为 **52800**；若重启后变化，应重新诊断，不要假设旧端口仍有效。
2. 通过 BrowserSkill 注入工具核验连接；使用可访问当前 DSH 的真实登录页面，不读取或导出 Cookie/令牌。
3. 只用新的、虚构演示会话；录制前避开用户会话列表、账户资料、路径和密钥。不覆盖真实白板。
4. 用户已批准原始 MP4 存放在本仓库 `docs/media/`，三段采用以下同名 MP4/GIF。原始 MP4 不默认公开；GIF 必须检查画面后再提交。
5. 开始录制后再进行操作；停止录制后保存，再离线转 GIF。等待片段如加速/省略，必须在说明中标注。失败不算录像，也不重复执行结果未知的写操作。

## A · 点一下，看清一跳关系（12–18 秒）

文件名：`reading-highlights.mp4` / `reading-highlights.gif`。

- 在新的“演示·流程”准备输入 → 校验 → 完成，另有未连接备注，连线使用显式绑定。
- 实录：更多 → 阅读模式 → 点击校验停留 → 空白清除 → 再点节点 → 退出阅读模式。
- 画面确实展示后才能写：点击高亮节点、直接相连节点与连线；空白清除。若录到退出后拖动，再说明可恢复编辑。
- 一段录像不能证明所有触屏/缩放/保存/撤销或导出行为。
